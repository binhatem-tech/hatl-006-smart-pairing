HATL-006 Smart Pairing

WebRTC × Supabase

مختبر تجريبي لربط جهازين عبر الإنترنت برمز اقتران، ثم إرسال بيانات تجريبية مباشرة عبر WebRTC. يستخدم Supabase لتبادل إشارات الاتصال فقط.

01 · الإعداد

الاتصال بـ Supabase

لا تستخدم Secret أو service_role. تُحفظ إعدادات الاتصال محلياً في هذا المتصفح فقط. أنشئ جدول الإشارات أولاً باستخدام ملف SQL المرفق.
